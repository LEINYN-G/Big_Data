## Big Data Foundations
====================

A research-oriented learning and experimentation repository
for Big Data Analytics, distributed systems, Hadoop, Java,
Linux, and scalable data processing.

### Focus Areas
-----------
- Linux and Git
- Java for Big Data
- HDFS
- Hadoop MapReduce
- Distributed Data Processing
- SQL
- Performance Experimentation

### Objective
---------
To build a strong foundation in distributed data systems
through hands-on implementation, experimentation,
benchmarking, and open-source practices.
